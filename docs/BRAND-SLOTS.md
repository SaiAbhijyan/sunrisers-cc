# Brand assets: where Sunrisers' own artwork lives

Everything brand-specific is isolated so it can be swapped without touching layout.

| Slot | File / place | What to do |
|---|---|---|
| Colours | `src/css/tokens.css`, block "BRAND SLOT 1" (`--ink`, `--sun`, `--flare`, `--paper`, `--on-*`) | Replace values only. Keep the names. Keep text/background pairs at 4.5:1 (7:1 for small text on black). Run `npm test` (axe) after. |
| Fonts | `src/css/tokens.css` "BRAND SLOT 2" plus `@font-face` at the top of `src/css/site.css`; font files in `src/assets/fonts/` | Self-host new woff2 files (no Google Fonts links: the CSP blocks them). Update the preload in `src/partials/layout.html`. |
| Wordmark (hero, OG) | Two hand-cleaned Milkstore 02 images from Sai (flat cream, hard alpha edges, no halo): `media/brand/wordmark-sunrisers-est-clean.png` (EST. 2017 + SUNRISERS, placed 1:1) and `media/brand/wordmark-cricket-club-nj-clean.png` (CRICKET / CLUB / arched NEW JERSEY USA, scaled 0.59 and centred under it so the spacing matches `home-reference.png`; layout constants in `tools/wordmark_src.py`). `python3 tools/trace-wordmark.py` composes them, upscales 8x (Lanczos), blurs half a pixel to round off pixel steps, cuts at 50 percent alpha, traces with potrace and optimises with svgo into `src/assets/img/brand/wordmark.svg` (one path, `currentColor`, viewBox 800x422), inlined in the home hero via `{{wordmark}}`. The same script renders `media/brand/wordmark-traced-2x.png` for the OG card; `python3 tools/compare-wordmark.py` writes the overlay and layout comparison images to `shots/brand/`. Needs `npm i --no-save potrace` (not a devDependency: it pulls in vulnerable jimp). Milkstore 02 itself is a paid Heritage Type Co. font and is not used or shipped. The earlier halo versions (`wordmark.png`, `wordmark-sunrisers-est.png`, `wordmark-cricket-club-nj.png`) are kept in `media/brand/` as history only. | Re-run both scripts after replacing either PNG. |
| Logo, texture | `media/brand/` (originals: `logo-phoenix.png`, `wordmark.png`, `texture.png`, `home-reference.png`; `logo-with-text.png` is an overlapping composite and is not used) | Run `python3 tools/build-brand.py`. It writes avif/webp/png (opaque textures: avif/webp/jpg) into `src/assets/img/brand/`, plus favicon, app icons and the 1200x630 OG image. The texture is recoloured to the reference by histogram matching. |
| Hero art | `.hero` block in `src/pages/index.html` (`picture.hero__tex` + centred `h1.hero__mark` wordmark) and `.hero*` / `.phero::before` / `.band--tex` / `.foot` in `site.css` | Re-run `tools/build-brand.py` after replacing a file in `media/brand/`. Accent tokens (`--sun`, `--sun-deep`) were sampled from `home-reference.png`; keep them at 4.5:1. |
| Photography | Team photos and match clips in `media/gallery/`. Optimized derivatives go to `src/assets/img/gallery/` and `src/assets/media/`; home photowall and `src/pages/gallery.html` consume them. | Add a metadata-stripped original under `media/gallery/photos/` or `videos/`, run `python3 tools/optimize-gallery.py` (and the video remux steps in that folder's README), then add the item to the gallery page. Keep images and video self-hosted so `img-src 'self'` and `media-src 'self'` hold. |
| Sponsor logos | `.sponsor-slot` in `src/pages/sponsors.html` and `index.html` | Replace with SVG/PNG logos plus links, with sponsor permission. |
| Copy | `src/data/club.json` (squads, league names, results) and `src/pages/*.html` | Placeholders are marked with the "Placeholder" tag. Remove the tag when real copy lands. |
| Domain | `SITE_URL` in `build.mjs` | Set before launch (canonical, sitemap, robots). |
| Contact endpoint | `data-endpoint` on `#contact-form` in `src/partials/form.html` | Point at a form backend; then add its origin to `connect-src` in `build.mjs` (`CSP`). Until then the form validates but sends nothing. |
